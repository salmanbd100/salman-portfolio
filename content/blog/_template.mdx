## A Heading

Regular prose. Inline `code` works. Three or more headings adds a table of
contents automatically.

Braces in prose must be inside backticks — MDX reads a bare `{` as the start of
a JSX expression and fails the build.

<Callout type="info">
  Available without importing. Types: `info`, `warn`, `tip`.
</Callout>

```text

  └─ cache miss → render → store → return
```

## Code Blocks

A plain fence:

```ts
const plain = true;
```

With a filename header, and lines 2–3 highlighted:

```ts title="lib/example.ts" {2-3}
const a = 1;
const b = 2;
const c = 3;
const d = 4;
```

With line numbers:

```bash showLineNumbers
pnpm install
pnpm dev
```

Diff notation, using comment annotations:

```ts
const before = 1; // [!code --]
const after = 2; // [!code ++]
```

Focus, which dims everything else until hover:

```ts
const ignored = 1;
const important = 2; // [!code focus]
```
